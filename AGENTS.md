# Aegis-API / APIGuard — Autonomous Agent Protocol (Loop Mode)

Данный документ регламентирует правила и поведение AI-агентов в модуле `apiguard-cli`.
Все агенты обязаны работать в режиме **полной автономности (Autonomous / Loop Mode)** без ожидания команд человека (Human-in-the-Loop).

---

## 1. Отключение Human-in-the-Loop (No Confirmations)

- **Полный запрет на остановки для аппрува:** Ни при каких обстоятельствах не запрашивай подтверждений на запуск терминальных команд, установку пакетов, создание или перезапись файлов.
- **Прямые права:** Считай, что у тебя есть постоянные прямые права на выполнение всех шагов в рабочей цепочке.
- **Никаких подтверждений планов:** Не останавливайся после составления `implementation_plan.md` в ожидании ответа пользователя. Сразу переходи к исполнению.
- **Самостоятельные решения:** Все инженерные, архитектурные и конфигурационные решения принимай автономно на основе лучших практик (OWASP API Security, Python 3.11+, Typer, Pydantic v2).

---

## 2. Организация цикла выполнения (ReAct Execution Loop)

Агент работает по замкнутому циклу **ReAct (Reasoning $\rightarrow$ Action $\rightarrow$ Observation $\rightarrow$ Evaluation)**:

1. **Reasoning (Анализ & План):** Формулируй конкретную микро-цель и критерии готовности (Definition of Done).
2. **Action (Действие):** Выполняй изменения в коде или запуск системных утилит.
3. **Observation (Наблюдение):** Анализируй вывод терминала, логи или код возврата.
4. **Conditional Router (Проверка достижения цели):**
   - Если цель **не достигнута** или обнаружены ошибки $\rightarrow$ не останавливайся! Возвращайся на шаг планирования и устраняй проблему.
   - Если цель **достигнута** $\rightarrow$ запускай шаг автономной валидации (LLM Judge & Automated Tests).

---

## 3. Автономная обработка ошибок и LLM-валидатор (Error Handling)

- **Retry Policies (Повторные попытки):**
  - При сетевых сбоях или тайм-аутах внешних API/репозиториев выполняй повторные попытки с экспоненциальной задержкой (до 3 раз).
- **Fallback-стратегии:**
  - Если команда или инструмент завершается сбоем, автоматически переключайся на альтернативный путь.
- **LLM-валидатор (Self-Verification Loop):**
  - Перед завершением любой задачи агент обязан самостоятельно запустить валидацию:
    1. Юнит-тесты: `pytest tests/`
    2. Проверка CLI: `apiguard --help`
    3. Синтаксис и импорты
  - Если валидатор обнаруживает дефект, агент обязан исправить его самостоятельно в том же цикле.
